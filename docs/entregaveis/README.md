# Revisão e apresentação do Projeto CS

Material produzido na revisão de **5 de setembro de 2026**, reunido nesta
pasta em 14/10/2026. É um registro daquela revisão: números do inventário e
resultados de testes citados no guia não descrevem necessariamente o estado
atual do código.

- `guia_completo_projeto_cs.md`: explicação do projeto e do pipeline.
- `inventario_completo_arquivos.csv`: inventário histórico do repositório.
- `revisao_projeto_cs_pipeline_v2.pptx`: apresentação final, com imagens incorporadas.
- `assets/`: imagens originais da apresentação.
- `previews/`: prévias selecionadas dos slides.
- `source/`: scripts e registros usados para produzir o material.

Os scripts em `source/` foram preservados com seus caminhos originais. A
geração da apresentação depende do runtime `@oai/artifact-tool` e de utilitários
locais do Codex. Para reutilizá-los, ajuste os caminhos e disponibilize esse
runtime. O PPTX e o guia podem ser abertos diretamente.
